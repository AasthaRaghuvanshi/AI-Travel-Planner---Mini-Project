# ✈️ TripWise – AI Travel Planner

TripWise is an AI-powered travel planning web application that helps users create personalized travel itineraries based on their destination, budget, interests, and preferences.

## 🌍 Features

- 🗺️ Select your travel destination
- 💰 Set your travel budget
- ❤️ Choose your interests and preferences
- 🤖 Generate personalized AI-based itineraries
- 📅 Get a day-by-day travel plan
- 🍴 Discover restaurants and places to visit
- 💾 Save your favorite trips
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- TypeScript
- React
- Vite
- CSS
- AI-powered travel recommendations

## 🎯 Objective

The main objective of TripWise is to make travel planning easier, faster, and more personalized by generating a complete travel plan according to the user's requirements.
